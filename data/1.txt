================================================================================
策略名称: 板块龙头共振识别策略（仅识别信号）
功能: 每日收盘后识别符合条件的个股，输出候选列表
================================================================================

================================================================================
一、初始化与数据准备
================================================================================

函数: 初始化策略()
    设置 选股池 = 全市场A股 - ST股 - 上市不满60日新股
    设置 板块分类 = 同花顺概念板块 或 申万二级行业分类 或 东方财富概念板块

    # 技术指标直接用现成库，不需要自己写
    导入 talib 库  # 用于MACD、布林带等
    导入 pandas 库  # 用于数据处理
    导入 numpy 库   # 用于数值计算


================================================================================
二、第一步：筛选主线板块
================================================================================

函数: 筛选主线板块(日期)
    主线板块列表 = 空列表

    遍历 每个板块 in 板块分类:
        计算 板块近3日累计涨幅
        计算 板块内近3日日均涨停家数
        找出 板块内连板天数 >= 4 的个股
        找出 板块内首个涨停时间最早的个股 作为 领涨龙头

        如果 板块近3日累计涨幅 排名全市场前5%
        并且 板块内日均涨停家数 >= 3
        并且 存在领涨龙头 且 领涨龙头连板天数 >= 3:
            将 板块 加入 主线板块列表

    对 主线板块列表 按 涨停家数降序、龙头连板高度降序 排序
    保留 前2个板块
    返回 主线板块列表


================================================================================
三、第二步：圈定候选跟风股
================================================================================

函数: 筛选候选跟风股(主线板块列表)
    候选股列表 = 空列表

    遍历 每个板块 in 主线板块列表:
        龙头 = 板块.领涨龙头

        遍历 板块内每只个股 in 板块:
            如果 个股 == 龙头:
                跳过

            计算 个股与龙头近60日日收益率皮尔逊相关系数
            找到 龙头首个涨停日期
            计算 龙头首个涨停当日 个股涨幅
            计算 龙头首个涨停当日 个股成交量 / 20日均量
            计算 个股近3个月最高价 与 当前价的距离百分比

            如果 相关系数 >= 0.7
            并且 龙头涨停当日 个股涨幅 >= 5% 或 成交量放大倍数 >= 1.5
            并且 当前价距离近3个月最高价 < 15%
            并且 流通市值 <= 300亿:
                将 个股 加入 候选股列表

    返回 候选股列表


================================================================================
四、第三步：技术信号共振确认（直接用现成库）
================================================================================

函数: 检查MACD金叉(个股)
    # 使用 talib 库，一行代码搞定
    diff, dea, macd_hist = talib.MACD(个股收盘价数组, fastperiod=12, slowperiod=26, signalperiod=9)

    计算 当日成交量 / 20日均量

    如果 今日DIFF > 今日DEA 并且 昨日DIFF <= 昨日DEA  # 金叉
    并且 DIFF值 >= -0.5
    并且 成交量放大倍数 > 1.0:
        返回 真
    否则:
        返回 假


函数: 检查布林通道买点(个股)
    # 使用 talib 库，一行代码搞定
    upper, mid, lower = talib.BBANDS(个股收盘价数组, timeperiod=20, nbdevup=2, nbdevdn=2)

    计算 中轨斜率 = 今日中轨 - 昨日中轨
    计算 成交量放大倍数 = 当日成交量 / 20日均量

    如果 今日收盘价 > 中轨
    并且 昨日收盘价 <= 中轨  # 今日站上中轨
    并且 中轨斜率 >= 0  # 中轨走平或向上
    并且 成交量放大倍数 >= 1.2:
        返回 真
    否则:
        返回 假


函数: 检查维加斯通道买点(个股)
    # 使用 pandas 的 ewm 方法，不需要额外库
    ema144 = 个股收盘价.ewm(span=144).mean()
    ema233 = 个股收盘价.ewm(span=233).mean()
    ema377 = 个股收盘价.ewm(span=377).mean()

    计算 维加斯通道上沿 = max(今日EMA144, 今日EMA233, 今日EMA377)

    如果 今日收盘价 > 维加斯通道上沿:
        返回 真
    否则:
        返回 假


函数: 技术信号共振筛选(候选股列表)
    识别结果列表 = 空列表

    遍历 每只个股 in 候选股列表:
        MACD满足 = 检查MACD金叉(个股)
        布林满足 = 检查布林通道买点(个股)
        维加斯满足 = 检查维加斯通道买点(个股)

        如果 MACD满足 并且 (布林满足 或 维加斯满足):
            信号详情 = {
                "代码": 个股.代码,
                "名称": 个股.名称,
                "所属板块": 个股.板块,
                "对应龙头": 个股.对应龙头,
                "相关系数": 个股.相关系数,
                "MACD金叉": 是,
                "布林买点": 布林满足,
                "维加斯买点": 维加斯满足,
                "当前价格": 个股.收盘价,
                "识别日期": 日期
            }
            将 信号详情 加入 识别结果列表

    返回 识别结果列表


================================================================================
五、主执行流程（仅识别，不买卖）
================================================================================

函数: 每日识别(日期)
    打印("===== 开始识别 =====")

    # 第一步: 筛选主线板块
    主线板块列表 = 筛选主线板块(日期)
    如果 主线板块列表 为空:
        打印("无主线板块")
        返回 空列表
    打印("主线板块:", 主线板块列表)

    # 第二步: 圈定候选跟风股
    候选股列表 = 筛选候选跟风股(主线板块列表)
    如果 候选股列表 为空:
        打印("无候选跟风股")
        返回 空列表
    打印("候选跟风股数量:", 候选股列表长度)

    # 第三步: 技术信号共振
    识别结果列表 = 技术信号共振筛选(候选股列表)
    如果 识别结果列表 为空:
        打印("无技术共振信号")
        返回 空列表

    # 输出识别结果
    打印("===== 识别结果 =====")
    遍历 每只个股 in 识别结果列表:
        打印(个股)

    打印("===== 识别完毕 =====")
    返回 识别结果列表


================================================================================
六、技术指标库说明（不需要自己写）
================================================================================

1. MACD、布林带、RSI、KDJ等常用指标:
   → 使用 talib 库
   → 安装: pip install TA-Lib
   → 用法: talib.MACD(), talib.BBANDS(), talib.RSI()

2. 移动平均线、EMA:
   → 使用 pandas 库
   → 用法: df['close'].rolling(20).mean(), df['close'].ewm(span=20).mean()

3. 相关系数:
   → 使用 pandas 库
   → 用法: df['return1'].corr(df['return2'])

4. 成交量相关:
   → 使用 pandas 库
   → 用法: df['volume'].rolling(20).mean()

总结: 所有技术指标都有现成库，不需要自己写公式


================================================================================
七、参数汇总
================================================================================

参数配置:
    板块涨幅排名阈值 = 前5%
    板块日均涨停家数阈值 = 3
    龙头连板天数阈值 = 3
    相关系数阈值 = 0.7
    跟风股异动涨幅阈值 = 5%
    跟风股异动量比阈值 = 1.5
    近3个月最高价距离阈值 = 15%
    流通市值上限 = 300亿
    MACD参数 = (12, 26, 9)
    MACD金叉DIFF阈值 = -0.5
    布林通道参数 = (20, 2)
    布林突破量比阈值 = 1.2
    维加斯通道参数 = (144, 233, 377)
